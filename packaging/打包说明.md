## 🚀 打包步骤（开发机执行）

### 1. 构建前端生产版本
```bash
cd apps/web
npx next build
```

### 2. 创建便携包目录
```bash
cd ~/Documents/张阗/ai-eos
mkdir -p ~/Desktop/AI-EOS-Portable/{apps,data,storage,logs,packaging}

# 复制后端
cp -r apps/api ~/Desktop/AI-EOS-Portable/apps/

# 复制前端（含 .next 构建产物）
cp -r apps/web ~/Desktop/AI-EOS-Portable/apps/

# 复制启动器
cp -r packaging ~/Desktop/AI-EOS-Portable/
```

### 3. 设置权限
```bash
chmod +x ~/Desktop/AI-EOS-Portable/packaging/*.sh
```

### 4. 打包成单文件（可选）
```bash
cd ~/Desktop
tar -czf AI-EOS-Portable.tar.gz AI-EOS-Portable/
# 或直接 .app 包
cp -r AI-EOS-Portable AI-EOS.app
```

## 🖥️ 使用说明

### macOS / Linux
1. 解压到任意位置
2. 双击 `packaging/start-mac.sh`（或 `start-linux.sh`）
3. 浏览器自动打开 `http://localhost:8000`

### Windows
1. 解压到任意位置
2. 双击 `packaging/start-win.bat`
3. 浏览器自动打开

## 🔧 故障排查

### 前端 500 错误
```bash
cd apps/web
rm -rf .next
npx next build
```

### 后端无法启动
检查端口占用：
```bash
lsof -ti :8000,8001 | xargs kill -9
```

### 数据库问题
先备份 `data/` 再重建——直接删库会丢失全部数据：
```bash
cp -r data "data-backup-$(date +%Y%m%d-%H%M%S)"
rm -f data/aieos.db
```
重启后自动重建数据库（空库）。恢复方法见 `docs/BACKUP_RUNBOOK.md`。
