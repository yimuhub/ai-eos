# 智能体备案材料清单（合规手册）

- 日期：2026-11-17；依据：三部门 2026-06 智能体备案要求 + 网信办《人工智能拟人化互动服务管理暂行办法》（2026-04）+《网安法》《数安法》《PIPL》
- 状态：**AI-EOS 对外提供生成式 AI 服务前必须完成**（销售前置条件）

---

## 1. 备案三件套

| 项 | 内容 | AI-EOS 落点 |
|----|------|------------|
| 大模型备案 | 所用基础模型须已备案（自研模型）/ 使用已备案第三方模型并做变更登记 | 模型中心记录每个 provider 的备案号；采购模型时核验供应商备案状态 |
| 算法备案 | 生成合成类算法备案（互联网信息服务算法备案系统） | 提交：算法基本原理、运行机制、数据来源说明 |
| 内容标识 | 生成内容显式+隐式标识 | **产品功能**：AI 产出（报告/消息/文件）带「AI 生成」标识——需开发 |

## 2. 拟人化互动服务办法要求的能力（产品开关清单）

- [ ] 用户隐私与个人信息保护声明（登录页/设置页展示）
- [ ] 过度依赖风险预警（会话内定期提示「AI 建议仅供参考」）
- [ ] 情感边界引导（数字员工人设不得替代真实社会关系——人设模板审查）
- [ ] 未成年人保护模式（可选开关）

## 3. PIPL 全生命周期义务（已有能力对照）

| 环节 | 义务 | AI-EOS 现状 |
|------|------|------------|
| 收集 | 最小必要 + 告知同意 | 登录协议 ✅；连接器拉数需客户系统授权（OAuth 托管 ✅） |
| 存储 | 敏感信息加密 | Fernet 保险库 ✅ / 静态加密部分 ⚠️ |
| 使用 | 目的限定 + 权限控制 | Capability 三层 + 行级 scope ✅ / 字段级权限 ⚠️ |
| 提供 | 对外提供需单独同意 | 出站 DLP 闸门 ✅（批量 PII 外发审批待加强） |
| 删除 | 主体权利响应 | 审计导出 ✅ / 数据删除请求流程 ⚠️ |

⚠️ = 差距项，进入 V6.2 计划。

## 4. 材料准备清单（提交用）

1. 服务协议 + 隐私政策（含 AI 生成内容免责条款）
2. 算法安全自评估报告（数据来源/模型安全/内容安全/用户权益）
3. 语料与训练数据合规说明（合法来源证明）
4. 内容安全：关键词库 + 审核机制说明（建议接内容审核 API 做双保险）
5. 应急预案（内容事故处置流程）
6. 用户投诉与举报通道（产品内入口——需开发）

## 5. 产品侧待开发项（排入 V6.2）

- 投诉/举报入口（工作台内一键举报员工产出）
- 依赖预警提示（会话周期性提示）
