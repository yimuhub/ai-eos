## 二、发现并已修复的问题（3 个）

1. **面板 iframe 永久卡在「正在校验登录状态…」**（P0，实测两次复现）：同一 tab 里第 2 个及以后挂载的面板 iframe，偶发**全部 JS chunk 加载为 0 字节**（performance 实测 transferSize=decodedBodySize=0，含 webpack/main-app/page/layout），React 永不水合。服务端 curl 正常、页面内裸 fetch 正常 → IAB/浏览器环境级加载竞态。
   **修复**：WorkspacePanel 新增「水合看门狗」——onLoad 4 秒后仍在 DOM 里找到 checking 文案就带缓存击穿参数重载一次（retry 防循环）。修复后实测：市场+指标中心两个面板连续挂载全部自救成功。
2. **市场安装成功后无任何状态反馈**（P1）：弹窗直接关闭，卡片无「已安装」，产物清单不展示——用户无法确认装了什么。
   **修复**：卡片加「已安装 ×N」徽标 + 按钮变「再次安装」；安装成功后弹窗保留展示 artifacts 与 notes。
3. **导航收敛约束破坏**（P2）：基座市场作为可见入口使侧栏可见数超 12，nav.test 红。
   **修复**：改 hidden（⌘K 可搜，侧栏收敛恢复）。

## 三、观察到的次要问题（未盲改，如实记录）

1. **单条消息瞬时网络失败**：演示种子完成后发的第一条消息被误报「无法连接后端服务」（<1s 失败）；同请求立即重试成功，服务端无痕。未能稳定复现（一次观察 + 一次市场安装同形态失败与 IAB 自动化点击相关），不排除真实用户网络抖动场景。建议后续：对 status=0 的写请求加「重试一次」按钮而非自动重发。
2. **合规台账无前端页**：/ops/compliance 数据与接口齐全，但没有任何 UI 入口（行业包种下的 4 条合规台账只能 API 看）。建议 V6.2 补「合规中心」页（到期预警可视化是这个引擎的价值出口）。
3. **toast 不自动消失**：错误 toast 会常驻并叠加（实测同文案两条叠放），需手动 ✕。
4. **demo 种子后右栏「公司管理」面板自动打开**：信息过载（新用户此时应聚焦对话），可考虑只开聊天。
