# 交付手册：AI-EOS 行业包部署（销售/实施用）

- 日期：2026-11-17；适用版本：v6.1.0+
- 面向：实施顾问 / 客户成功。目标：新客户从签约到「首月真的在用」≤ 5 个工作日。

---

## 1. 交付包构成（每行业）

一个行业包买回去 = 以下六件套（安装一个包自动种好前四件）：

| 件 | 内容 | 载体 |
|----|------|------|
| ① 行业数据模型 | 扩展字段（custom_field_defs） | 行业包安装 |
| ② 预配员工编制 | 5-8 名数字员工（带能力包，不绑模型） | 行业包安装 |
| ③ 工作流图纸 | 8-10 条行业流程（草稿，审后发布） | 行业包安装 |
| ④ 合规台账 | 罚则级证照 + 年审规则 + 到期预警 | 行业包安装（compliance_items） |
| ⑤ 指标看板 | 行业指标（预配口径，需接线） | 行业包安装 |
| ⑥ 连接器蓝图 | 该行业数据源清单 + 接入方式 | 行业包 manifest.integration_targets |

安装入口：**基座市场 → 行业包 → 安装到公司**（需公司 MANAGE + 权限确认；全程可回滚）。

## 2. 标准实施日历（5 个工作日）

| 日 | 动作 | 责任人 | 验收 |
|----|------|--------|------|
| D1 | 建司 → 装行业包 → 预配员工配模型（BYOK 录入） | 实施 + 客户 IT | 员工可对话 |
| D2 | 连接器接线：装连接器包 → OAuth/API Key 授权 → 首次全量拉取 → 挂增量调度 | 实施 + 客户系统管理员 | /connectors 显示 success 且行数与源系统抽样一致 |
| D3 | 指标接线：把预配指标的 spec 绑到连接器字段（或修 mapping）→ 逐个求值对数 | 实施 + 客户财务/业务 | 指标求值与客户现有报表一致 |
| D4 | 工作流发布：审行业包预置的草稿流程 → 改参数 → 发布 → 跑一条真流程 | 客户老板 + 实施 | 一条流程端到端跑完，产出交付件 |
| D5 | 合规台账确认：逐条核对证照有效期/责任人 → 到期预警演示 → 培训（老板 1h + 员工 2h） | 实施 | 客户签收《首月验收单》 |

## 3. 首月自动化日历（和客户一起勾选）

安装完成后，和客户逐条确认哪些自动动作要开（全部走 automation/scheduler）：
- [ ] 每日晨报（含行业指标区 + 合规临期区）— 建议全开
- [ ] 连接器增量同步（默认每 30 分钟，可调）
- [ ] 合规台账到期预警（expiring 状态 → 派单给 owner_agent）
- [ ] 周报/月报生成（doc_generator 按行业模板）
- [ ] 对账任务（有银行/平台流水的客户）

## 4. 验收清单（首月）

- [ ] ≥3 条工作流跑过 ≥10 次，成功率 ≥80%
- [ ] ≥5 个指标有自动数据源且与客户报表对上
- [ ] 合规台账全部录入且临期预警验证过一次
- [ ] 老板每周至少 3 天打开工作台（看简报/审批/指标任一）
- [ ] 一次「老板接管」实操演练完成

## 5. 需要客户/商务配合的事项

- **ISV 资质**：接入电商三平台/美团/医保/电子税务局需要以公司名义申请开放平台 ISV 资质（分行业分批，见商业交付差距清单 §P0-3）——商务提前 2-4 周启动
- **金蝶/用友专用签名连接器**：需要客户测试账套凭据联调
- **智能体备案**：对外提供生成式 AI 服务前完成大模型备案/算法备案/内容标识（见 `docs/合规_智能体备案材料清单_2026-11-17.md`）
