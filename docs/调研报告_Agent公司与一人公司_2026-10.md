# AI-EOS 行业对比调查报告（2026-10）

> **调研对象**：「Agent 公司 / 一人公司 AI 工作台」赛道的真实产品与框架
> **调研时间**：2026 年 10 月 18 日（3 路并行深度调研 + 交叉检索）
> **目的**：把我们的功能与行业对标，找出"值得抄的"和"我们独有的"
> **阅读时间**：约 15 分钟

---

## 一、TL;DR（核心结论，8 条）

1. **赛道真实存在且在加速**："一人公司"（一个人 + 一队 AI 员工）在 2026 年初从概念变成产品——Tycoon（AI CEO + 高管团队 + 晨间简报）、Polsia（"零人类公司"，30 天 $1M ARR）、Paperclip（给 Agent 发组织架构/预算/审计日志）都已商业化。a16z 把"输入框消失、语音 Agent 崛起"列入 2026 三大论点。
2. **我们的组织隐喻是护城河**。行业主流是"员工列表"（Lindy）或"临时调用的子 Agent"（Genspark）；只有 Relevance AI（"AI Workforce"）和扣子 3.0（多 Agent 协作 + 组织/项目）摸到了"公司"概念。**公司→部门→岗位 Agent 的完整生命周期（招聘-培训-考核-晋升-交接）是全行业独一无二的**，应做成 HR 看板强化。
3. **最大的功能缺口：CEO 晨间简报 + 审批门 + 预算帽**。一人公司产品的共识交互是"每天 10 分钟给 AI CEO 指方向，它汇报昨天干了什么/今天计划/需要你决策什么"。我们有干预中心和审计日志，但**没有"早上好"式的每日汇总入口**；高风险动作（发邮件/发公众号/执行破坏性命令）**没有统一的老板确认点**（与我们的产品设计哲学直接冲突）。
4. **HITL（人工介入）是开源框架的成熟范式**：LangGraph 的 interrupt/pausable checkpoint、Temporal 的 wait-for-approval signal、OpenAI SDK 的 guardrails 早停。我们的检查点续跑是"失败重试"型，**应升级为"可暂停-人工接管-恢复"型**。
5. **MCP 已成事实标准**：扣子、n8n、Dify、Gumloop 全支持 MCP 插件/服务器。我们应双向做：**会议引擎/工作流引擎/文档交付暴露为 MCP 工具，同时能接入外部 MCP 服务器**，让外部 Agent 生态能调用我们的公司能力。
6. **桌面版 + 局域网共享 + 免密配对 + 一键部署是纯差异化**：调研的所有产品（Lindy/Gumloop/Relevance/Coze/Tycoon/Polsia）全是云端 SaaS，**没有一个做本地桌面 + 局域网 + 设备吊销的**。这条路线没人抄我们，继续加深。
7. **计费要学 Lindy 的"超额即暂停"**，别学 Relevance 的"超额单价贵 10 倍"（2026 年用户吐槽最多的坑）；Gumloop 的"默认不设超额、要超得手动开、且设上限"是次优方案。我们的六维计量已有基础，缺**部门/岗位维度的虚拟账户与预算帽**。
8. **垂直化建议**：不碰"艺人 AI 分身"（强 IP 依赖、法律红线多），改做**"一人公司部门 Agent 包"（销售/客服/内容/财务/法务 5 个岗位模板 + 晨间简报 + 审批门）**——这是 Music Mogul AI 已验证付费意愿（$300/月/Agent）的形态，且完全落在我们现有组织模型内。

### 2.2 计费模式踩坑榜（2026 实测，直接决定我们怎么设计 Token 计费页文案）

- ❌ **Relevance**：套餐外单价是套餐内 10 倍，用户骂最惨；
- ✅ **Lindy**：积分耗尽 → Agent **暂停并告知**，永远不产生超支账单（最安全的失败模式）；
- ✅ **Gumloop**：超额默认关，手动开且有硬上限（$5000）；**失败调用免费**；
- 💡 结论：我们的"六维 Token 统计 + PricingConfig"应加一条**"部门预算帽 + 超额即暂停 + 明确提示"**，UI 上把"还能干多少活"做成进度条（对标 Tycoon 的 $50-500/月全 C 级高管叙事，我们桌面版"近乎无限本地算力"是天然卖点）。

### 4.2 一人公司场景的交互共识（从 8 个产品抽象出的 5 条）

1. **一个入口：AI CEO / 经理**（Tycoon/Astra、Polsia/CEO、Agentfounder）——老板只对一个"总经理"说话，它负责拆解分派。**我们已有（CEO 任务编排），但要把它做成"每天主动汇报"的角色**。
2. **晨间简报**（Tycoon morning briefing、Polsia 邮件）：昨日完成/今日计划/需你决策的 3 件事。**我们完全没有这个入口**。
3. **自主边界 + 升级机制**（"在权限内做，碰边界就升级给老板"——Tycoon 原话：agents with judgment, act inside autonomy boundary, escalate at the edge）。**对应我们的"老板可视化确认点"哲学，目前缺统一实现**。
4. **预算即管理手段**（Agentfounder 的 mission+budget；Relevance 的 vendor credits）：给 Agent 配"钱"，超了自动停。
5. **把"公司"实体化**（Paperclip 的 org chart/工单/审计日志；Cofounder 的 org chart+roadmap）：**这是我们最强的既有能力**，缺的是把审计日志做成"可回放的公司动态"。

### 4.3 趋势信号（a16z Big Ideas 2026 / opcreport）

- 输入框消失、**语音 Agent 崛起**（Vapi $50M B 轮、10 亿+ 通话；Numa/GetDandy/MessageMind 抢本地商家"永不占线的电话前台"）；
- GitHub `solopreneur` 主题 137 个公开仓库，"用邮件协作、共享记忆、越用越强的 AI 员工"是高频模式；
- **一人公司的下一站：把 Agent 能力打包成"某垂直行业的数字员工"卖订阅**（语音前台/多 Agent 协调/Agent QA 三层，solo founder 可转售）。

| 技能/插件市场 | ⚠️ 技能成长档案 | 扣子技能商店（含企业私有市场）、Gumloop MCP 托管 | **落后 P1** |
| MCP 支持 | ❌ | 扣子/n8n/Dify/Gumloop 全有 | **缺口 P1** |
| 可观测（节点级 trace/回放） | ⚠️ 审计日志 | LangSmith/LangFuse/n8n 集成 | **落后 P1** |
| 桌面 + 局域网 + 免密配对 + 吊销 + mDNS + 自动升级 | ✅✅✅ | **调研产品全部没有**（全云 SaaS） | **独有领先（护城河）** |
| 系统诊断 | ✅ | self-hosted-ai-stack 的 doctor 有类似 | 持平偏强 |
| 交付物（PPT/Word/Excel/MD 真实文件） | ✅ | Manus/Genspark 同型 | 持平 |
| Agent 专属邮箱/全渠道副手 | ❌ | 扣子 Agent 邮箱、CoFounder 电话/短信 | P2 观察 |
| 岗位 Agent 模板（SDR/客服/内容/财务一键雇） | ⚠️ 有团队生成器 | Lindy/Founderr/Tycoon 模板市场 | **缺口 P1** |

## 七、升级方案（按优先级，全部映射到现有模块）

### P0（下个版本就做，一周内可落地）

1. **CEO 晨间简报**（学 Tycoon/Polsia）：新增 `/briefing` 首页区块——"昨夜自动任务结果 / 今天计划执行项 / 需要你决策的 3 件事"，数据全部来自现有审计日志 + 任务表 + 自动化引擎，**零新表**。老板打开 App 第一眼就是这个。
2. **动作级审批门**（学 Lindy/Music Mogul + 我们的设计哲学）：Computer Agent 破坏性命令、对外发布（发文件/发内容）类动作默认"起草完成 → 等老板点确认"，与"验收考试 Agent 现场作答"同一交互范式；审批记录进审计日志。
3. **预算帽 + 超额暂停**（学 Lindy）：任务/Agent 可选配 Token 预算，达到即暂停并提示（不自动扣超额）；六维计量页加"还能干多少"进度条。

### P1（两周内）

4. **HITL 检查点升级**（学 LangGraph interrupt）：长任务检查点加 `paused` 状态——老板可"暂停→接管改方向→从检查点恢复"，替代现在只有"失败重试"。
5. **MCP 双向**（学扣子/n8n）：① 把工作流引擎 + 会议引擎 + 文档交付暴露为 MCP 工具；② Agent 技能槽支持"外接 MCP 服务器"。让外部生态（Claude Code/Codex）能调用"我的 AI 公司"。
6. **岗位 Agent 模板市场**（学 Lindy/Founderr/Music Mogul 验证过的付费点）：5 个岗位包（销售/客服/内容/财务/法务）一键雇佣，每个带人设+技能包+考核标准；桌面版可离线预装。
7. **节点级 trace**（学 LangFuse）：任务详情页加"执行轨迹"时间轴（每个 Agent 每步的输入/输出/token 消耗），失败可定位到具体节点；数据复用 token_usages + 审计日志。

### P2（观察/择机）

8. 公司 HR 看板（编制/成本/产出/考核分）+ 考核量化（交付物自动评分：PPT 一致性、Excel 可复算、公文要素齐全率）——护城河深化。
9. 交付流水线"计划/审批/执行"三分离（学 Temporal）：公文/汇报类先出草稿+计划，老板批了才执行。
10. Agent 专属邮箱/全渠道副手（学扣子/CoFounder）：一人公司的"可被外部联系"能力。
11. 语音前台（a16z 2026 论点）：本地"永不占线"的电话/语音 Agent，桌面版特色。

## 八、风险提醒（2 条）

1. **同质化风险**：工作台形态 SaaS 端已经很挤（Lindy/Gumloop/Relevance/Coze 全在做"岗位 Agent"）。我们的差异化锚点只有三个：①组织隐喻（公司 vs 员工列表）②本地桌面+局域网（别人全云）③老板确认点文化（别人的审批门是合规摆设，我们的是产品核心叙事）。**P0 三条全为强化①②③服务，别去抄别人的云 SaaS 功能**。
2. **一人公司产品的"信任悬崖"**：Polsia 式"AI 夜间自驱经营"演示很猛，但用户真实使用中失控动作（乱发邮件/乱花钱）会瞬间杀死信任。**我们的解法就是"老板可视化确认点"——高风险动作永远停在老板面前，宁可慢不可错**。晨间简报给"可控的自动化感"，而不是"全自主"。
