# AI-EOS 专家库 · 原创声明

> 本声明随产品发布，同时展示于专家库页面顶部横幅（可折叠）。

## 一、借鉴了什么

本库约 20 个工种部门、共 262 位 AI 专家角色，其**工种划分框架与组织方式**，参考了开源项目
[jnMetaCode/agency-agents-zh](https://github.com/jnMetaCode/agency-agents-zh)（MIT License）。

工种划分（"哪些职业/角色被纳入专家库"）属于**行业通用的概念性分类**，任何团队都可以按相同思路列出
"工程、市场、财务、法务、可研、文案……"这些类别，这类思想层内容不构成受版权保护的表达，
因此本库直接沿用了这套分类框架，无需授权。

## 二、我们完全重写的是什么

本库中**全部 262 位专家的每一个人设内容**——包括「身份与记忆、核心使命、关键规则、交付物、
工作流程、沟通风格、成功指标、进阶能力」等所有章节的文字表达——

**均由 AI-EOS 团队使用 LLM 独立完整重写，为 AI-EOS 原创作品。**

重写过程严格遵守以下合规红线：

1. **不把上游任何原文喂进生成过程**。LLM 收到的输入仅为「职业名称 + 所属部门 + emoji」这类
   事实/概念层信息（即"要设定一个什么职业"），上游专家文件里的正文一字未作为 prompt 输入。
2. **生成后再做相似度硬拦截**。每个生成结果都会与上游原文做 10-gram 相似度比对，
   若出现明显雷同（占比超阈值）自动重生成，确保没有照搬、改写或翻译。
3. **产物全部重新署名**。数据库与页面中这些专家的 `source = ai-eos-original`、
   `license = AI-EOS 原创`，不再显示"MIT 许可"。

按 MIT 协议要求，我们对所参考的上游项目予以署名，其原始许可保留在
[`vendor/agency-agents-zh/LICENSE`](../vendor/agency-agents-zh/LICENSE)：

- 上游作者：Michael Sitarzewski（original English version）等贡献者
- 我们仅参考其"工种分类框架"（思想层），**未复制其任何表达层内容**，
  故上游 266 份专家人设原文不再作为本库的授权来源，仅在 `vendor/` 目录合规留档。

## 四、一句话总结

**参考了别人的"框架"（合法且已署名），重写了所有的"内容"（AI-EOS 原创）。**
因此本专家库的全部内容权利归 AI-EOS 所有，可随产品商业化自由使用与分发。
