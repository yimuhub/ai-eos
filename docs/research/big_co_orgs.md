### 1.1 架构要点（2025–2026）
- 基线架构：2021-11 起实行业务线 BU 化，六大板块（抖音/大力教育/飞书/火山引擎/朝夕光年/TikTok），各板块负责人直报 CEO 梁汝波；无 CFO（财务直报 CEO）。2025 年实际核心业务线：抖音（含电商/直播）、TikTok、飞书（企业协同）、火山引擎（云+MaaS）、豆包（C 端 AI）、Seed（大模型研发，梁汝波/朱文佳体系）、游戏（沐瞳+朝夕光年，张云帆 2024-05 接手，向华巍汇报）、PICO 等【待核实：PICO 现状】。
- 2025-06（火山引擎 FORCE 大会）：CEO 梁汝波定调「攀登 AI 高峰是当下最重要的事」，火山引擎 MaaS 升级为基础业务。
- **2025-11~2026 上半年**：游戏业务继续收缩（朝夕光年 2023-11 大裁撤后 2024-03 回「孵化状态」，2025 年传与沐瞳合并、规模约 1000 人，无上市计划——来源：36 氪/中国企业家）。
- **2026-07-30 关键调整（多源确认：21 财经/科技日报/国际金融报）**：
  1. 飞书产品团队并入豆包产品团队，成立新豆包产品团队（豆包负责人赵祺，飞书负责人谢欣向赵祺汇报）；

## 15. 综合建议：最值得仿照做「一人公司数字团队预设包」的 3 家

### 推荐 1：字节跳动（仿「中台 BU 化 + AI 全栈」，做默认旗舰预设）
- 理由：① 业务线按「内容→AI→ToB」单链组织，逻辑天然适配一人公司「一个老板、一条增长链」；② 2026-07 的「豆包（模型）—飞书（入口）—火山引擎（GTM）」整合范式，正好是一人公司「模型 Agent—产品 Agent—销售/客户 Agent」三段闭环的原型；③ 无 CFO、财务直报 CEO 的扁平治理，与一人公司「老板直管一切」同构；④ 中文语境、岗位命名贴近国内用户习惯。
- 落地：10 部门（战略/产品/研发/算法/市场/销售/客户成功/供应链/法务/财务HR），默认「大厂标准版」预设包。

### 推荐 2：月之暗面/Moonshot（仿「300 人密度 + API 商业化」，做 AI 原生精简版）
- 理由：① 300 人规模最接近「一人公司=1 个老板 + N 个数字员工」的放大比，8 部门即可覆盖全职能，不稀释人格设定；② 2025–2026 从 C 端助手到 API 商业化的重排（张予彤总裁 + API 独立分支）展示了「产品先行→模型杠杆→API 变现」的演进路线，可做成「成长路径预设」；③ 开源+闭源双线的岗位（开源经理/社区经理）是其他大厂没有的特色，适合创作者型一人公司。
- 落地：8 部门精简预设，面向「AI 产品创业型」老板；与 DeepSeek 合并为「中国 AI 实验室」预设（研究密度优先 vs 商业化优先两种人设）。

### 推荐 3：Anthropic（仿「安全刹车 + 双 CEO 制」，做治理增强模块/预设）
- 理由：① 「CEO 只管 1 个直报 + 总裁统全局」是数字团队里最干净的「老板 Agent + 管家 Agent」映射，可直接生成「决策者 + 运营者」双 Agent 骨架；② RSP/ASL「发布门槛 + 可追溯决策记录」机制，是一人公司「什么该发给客户、什么先内部测试」的完美制度原型——每个数字员工可带一条「发布前检查单」；③ 安全部 6 岗（红队/护栏/合规/评估/RSP）让「质量与风控」第一次在大厂预设里成为一级部门，补上现有预设包缺失的「刹车系统」。
- 落地：可作为「治理增强」叠加预设（给任意预设包加 1–2 个刹车型 Agent），或独立成「安全与合规办公室」预设。

> 组合建议：字节（业务主干）+ 月暗（AI 密度与商业化）+ Anthropic（刹车与治理）= 一人公司数字团队的「攻-攻-守」三预设，正好覆盖 AI-EOS 现有 pack_sales/pack_support 之外的「组织形态」维度。
