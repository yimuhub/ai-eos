Computer Access

电脑权限

决定数字员工能在你的电脑上做多少事。三档模式可随时切换，切换只影响后续动作，历史审计不受影响。

默认审批推荐

只读操作直接执行；写文件、执行命令、启动应用逐次弹出审批。最稳妥，适合刚启用电脑操作的团队。

自动审批

白名单目录、命令与应用自动放行；白名单之外仍然逐次审批。适合已经跑顺的固定流程。

完全控制高风险

不逐次审批，全盘读写与执行。仍保留灾难性操作、凭据读取、终端宿主键入的硬拦截，并按会话限时。

所有模式一律硬拦截（不可关闭）
  • 读取 ~/.ssh、~/.aws、.env、钥匙串与浏览器密码库
  • rm -rf /、格式化磁盘、覆盖系统目录等灾难性命令
  • 向终端宿主（Terminal / iTerm）本身键入内容
  • 对受保护分支执行 git push --force、改写历史
  • 未经批准的外联上传（含把本地文件发往陌生域名）
